# MERN Stack Learning Repository

This repository contains the projects and practical work completed while learning the MERN Stack from the fundamentals to full-stack development.

## Project 1 – Student Portal

The first project is a **Student Portal website** created using **HTML5 and CSS3**. It focuses on building the basic structure and design of a multi-section website.

### Sections
- Main/Home Page
- Student Registration Page
- Media Section

### Concepts Learned
- HTML5 structure and semantic elements
- Headings, paragraphs and lists
- Links and navigation
- Forms and input fields
- Tables
- Images and multimedia
- CSS styling
- Colors, fonts and backgrounds
- Margins and padding
- Borders
- Flexbox
- Basic page layout

### Tech Stack
- HTML5
- CSS3

This project is the starting point of the MERN Stack learning journey and focuses on understanding the fundamentals of frontend development.
